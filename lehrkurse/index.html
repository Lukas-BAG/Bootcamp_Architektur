Vom Bauplan zum Code

Dieser Bootcamp bringt dir bei, ein Softwareprojekt bevor die erste Zeile Code geschrieben wird sinnvoll zu planen, und wie du Code danach so strukturierst, dass er in einem Jahr noch änderbar ist — mit den Prinzipien, Mustern und Architekturstilen, auf denen professionelle Softwareentwicklung aufbaut. Jedes Modul kombiniert kurze Theorieblöcke mit interaktiven Visualisierungen und Übungen; die Java-Aufgaben dazu liegen in code/ und sind direkt in IntelliJ lauffähig.

Reihenfolge

Die 6 Module

Die Module bauen aufeinander auf: Modul 0 klärt, was überhaupt gebaut werden soll, bevor Modul 1–4 zeigen, wie man es sauber baut. Modul 5 ist die Fallstudie, die alles zusammenführt. Du kannst trotzdem gezielt einzelne Module ansteuern, wenn du an einem Thema schon fit bist — schau dir dazu vorher kurz die Selbstcheck-Karten am Ende des jeweiligen Moduls an.

Modul 00 Vom Problem zum Plan Anforderungen, User Stories, MVP-Scoping, Architecture Decision Records und wie man einen Tech-Stack begründet auswählt. Modul 01 SOLID-Prinzipien Die fünf Grundprinzipien für wartbaren objektorientierten Code — mit Vorher/Nachher-Beispielen statt Merksätzen. Modul 02 Design Patterns Strategy, Factory Method, Observer, Adapter, Decorator und die Fallstricke von Singleton. Modul 03 Architekturstile Schichtenarchitektur, MVC, Clean/Hexagonal Architecture und wann sich Microservices überhaupt lohnen. Modul 04 Modularität, Kopplung & Kohäsion Wie man Module so schneidet, dass Änderungen lokal bleiben — und woran man schlechte Schnitte erkennt. Modul 05 Fallstudie: Kleines System Ein kleines System von der Anforderung bis zur Architektur-Entscheidung durchdenken — alles vorherige im Zusammenspiel.
